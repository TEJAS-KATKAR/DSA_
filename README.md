# DSA — JavaScript

A collection of **Data Structures and Algorithms problems solved using JavaScript**.

The repository contains problems practiced while learning DSA, organized by topic and difficulty.

## ▶️ Running the Code

Make sure [Node.js](https://nodejs.org/) is installed, then run any file with:

```bash
node filename.js
```

Example:

```bash
node basics.js
```

## 🔄 Progress

This repository will be updated as new DSA topics and problems are completed.
